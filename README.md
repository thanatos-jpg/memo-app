# ことば帳

読んだ本・note・論文の中から「思考の助けになった言葉」を、出典つきで集めて整理するメモアプリです。
スマホのホーム画面に追加して使えるPWA(依存ライブラリなし・ビルド不要)です。

## できること

- 言葉・文章を保存して見返す(1件 最大30,000字)
- 出典を必ず残す(種類・タイトル・著者・ページ/位置・URL)
- 分野(ビジネス・哲学など)とタグ(話題)で整理、全文検索、並び替え
- 自分のメモ欄(その言葉で考えたこと)
- 「引用をコピー」(本文+出典を整形してコピー)
- JSONバックアップ/復元、Markdown書き出し(分野別)
- オフラインで動作、ダークモード対応
- Androidでは他アプリの「共有」からそのまま追加可能(ホーム画面に追加後)

### 文字数について

保存できる長さは長め(30,000字)にして、見やすさは表示側で解決しています。
一覧では6行で切って「続きを読む（全N字）」を表示し、タップすると全文を表示します。
短い名言も、note記事の丸ごと保存も同じ画面で扱えます。上限は `app.js` の `MAX_CHARS` で変更できます。

## 使い方

静的ファイルだけなので、どこにでも置けます。

```sh
python3 -m http.server 8000   # → http://localhost:8000
```

スマホで使うには、HTTPSで公開します(例: GitHub Pages — Settings → Pages で対象ブランチのルートを指定)。
公開したURLをスマホで開き、
iPhone: 共有 →「ホーム画面に追加」/ Android: メニュー →「アプリをインストール」。

## データの保存先

データは端末のブラウザ内(IndexedDB)にあり、サーバーには送信されません。
そのため **端末間の自動同期はありません**。機種変更や複数端末で使う場合は、メニューの「JSONで書き出す／読み込む」を使ってください。
ブラウザのサイトデータを消去すると保存内容も消えるので、時々バックアップを取ることをおすすめします。
